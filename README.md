# 📈 Financial News Sentiment Analysis using FinBERT

A transformer-based NLP project that analyzes Indian financial news headlines using the **FinBERT** model to classify sentiment as **Positive**, **Neutral**, or **Negative**. The project demonstrates how domain-specific language models can extract market sentiment and provide actionable insights for financial analysis.

---

## 📌 Project Overview

Financial news significantly influences market movements and investor sentiment. This project leverages **FinBERT**, a transformer model pre-trained on financial text, to classify sentiment from news headlines and analyze sentiment trends over time.

---

## 🎯 Objectives

- Classify financial news into Positive, Neutral, and Negative sentiment.
- Generate confidence scores for each prediction.
- Analyze sentiment distribution across the dataset.
- Visualize temporal sentiment trends.
- Demonstrate the application of NLP in financial market analysis.

---

## 📂 Dataset

- **Source:** Indian Financial News Headlines Dataset
- **Records:** 50,000+ headlines
- **Features:**
  - News Headline
  - Publication Date
  - Source (if available)
